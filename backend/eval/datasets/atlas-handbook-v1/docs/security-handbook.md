# Information Security Handbook

Owner: Security Team. Applies to all employees, contractors, and interns.

## Accounts and authentication

Multi-factor authentication is mandatory for every company account. Hardware security keys are required for administrators and for anyone with production access; everyone else may use the Authenticator app. SMS codes are not accepted as a second factor.

Passwords must be at least 14 characters long and must be stored in the company password manager, Vaultline. Passwords must never be reused across services.

## Reporting incidents

Suspected security incidents, including phishing emails, lost devices, and accidental data sharing, must be reported to the security desk within one hour of discovery. Report through the #security-help channel or by calling the security hotline at extension 4040. Do not try to investigate an incident yourself.

## Data classification

Northwind data has four classes: Public, Internal, Confidential, and Restricted. Customer robot telemetry and source code are Confidential. Personal data about employees and customers is Restricted and may only be stored in approved systems.

## Device security

Laptops must use full-disk encryption and receive security updates within seven days of release. USB storage devices are blocked on company laptops; use the approved file-sharing service instead.

## Access reviews

Managers review their team's access to production systems every quarter. Access that is no longer needed must be removed within five working days of the review.
